HUONG DAN MO VA CHAY PROJECT

1. Giai nen thu muc MyStore_MVC5_Clean.
2. Mo file MyStore_MVC5.sln (nam ngay trong thu muc nay). Khong mo cac file .csproj nam trong App_Data hoac Views.
3. Trong Visual Studio, chon Build > Restore NuGet Packages (neu duoc hoi).
4. Chon Build > Clean Solution, sau do Build > Rebuild Solution.
5. Trong Solution Explorer, chuot phai project MyStore_MVC5 > Set as Startup Project.
6. Chay bang IIS Express (F5).

Yeu cau moi truong: Visual Studio co workload ASP.NET and web development, .NET Framework 4.8 Developer/Targeting Pack, va SQL Server Express LocalDB (vi Web.config dang ket noi (LocalDB)\MSSQLLocalDB).

Neu loi Parser van con, dong Visual Studio, xoa thu muc .vs neu Visual Studio da tao lai, mo lai dung file .sln o buoc 2 va Rebuild.
